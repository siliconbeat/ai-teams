# 0.9.2

## 修复与验证

- 保留一键清空服务端任务及 Mission 历史、等待中（queued）筛选。
- 增加进程组取消、本地执行期限、关闭期间拒绝新任务，以及超时后的执行槽取消屏障。
- 完成结果持久化后重发，服务端确认后移除；重连先核对离线结果，再派发新任务。
- 日志失败不阻断任务结算；会话状态原子写入，持久化异常时暂停接受新任务。
- 明确要求成功 result，限制摘要、JSON 行和输出缓存大小，增加日志容量限制。
- Agent restart 等待旧进程退出，PID 操作核验进程身份，异步查询 Claude 版本。
- 本地 macOS：189 项自动测试、类型检查、构建及包入口验证通过。未调用真实模型或清理生产数据。

## 升级注意事项与已知限制

- 先升级 Server，再升级 Agent，以支持完成结果确认协议。
- 使用旧版本先停止正在运行的旧守护进程，再安装新版本。新版本拒绝对无法验证身份的旧纯数字 PID 文件发送信号；遇到此情况应人工核对进程，不能直接删除活跃 PID 文件后重复启动。
- 离线任务保留执行归属，不再由另一台 Agent 自动重放执行状态未知的任务。
- Agent/watchdog 被 SIGKILL 后的孤儿进程、独立脱离进程组的后代、Windows 进程树，以及 Server 重启后的取消屏障仍未完全覆盖。不承诺任意崩溃窗口下 exactly-once。
- 尚未完成生产 Linux、PostgreSQL 和长时间压力验证。
- 升级不等于部署，也不会自动清理现有服务器磁盘、Claude 历史、系统日志或 Docker 数据。
