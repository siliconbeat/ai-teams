# 发布流程

## 前置条件

1. 已登录 npm 账户（需要有 `@csdwd` scope 的发布权限）

```bash
npm login
```

2. 确认 npm registry 指向官方源

```bash
npm config get registry
# 应该是 https://registry.npmjs.org/
```

## 发布步骤

### 1. 构建

```bash
pnpm build
```

这会依次：
1. 编译 `@ai-teams/shared`（TypeScript → dist）
2. esbuild 打包 `@csdwd/ai-teams-server`（内联 shared，输出 `dist/index.js`）
3. esbuild 打包 `@csdwd/ai-teams-agent`（内联 shared，输出 `dist/index.js`）

### 2. 运行测试

```bash
pnpm test
```

确保 60 个测试全部通过后再发布。

### 3. 发布

```bash
# 进入 server 目录发布
cd apps/server
npm publish --access public
cd ../..

# 进入 agent 目录发布
cd apps/agent
npm publish --access public
cd ../..
```

### 4. 验证

```bash
# 全局安装测试
npm install -g @csdwd/ai-teams-server
npm install -g @csdwd/ai-teams-agent

# 验证命令可用
ai-teams-server --help
ai-teams-agent --help
```

## 版本更新

修改版本号后重新发布：

```bash
# 在对应包目录下修改 package.json 中的 version 字段，然后：
cd apps/server
npm version patch  # 0.1.0 → 0.1.1
npm publish --access public

cd ../..
cd apps/agent
npm version patch
npm publish --access public
```

## 包信息

| 包名 | 命令 | 产物大小 |
|------|------|----------|
| `@csdwd/ai-teams-server` | `ai-teams-server` | ~67KB |
| `@csdwd/ai-teams-agent` | `ai-teams-agent` | ~36KB |

`@ai-teams/shared` 不单独发布，构建时已内联到上述两个包中。

## 注意事项

- 两个包版本号建议保持同步
- `@ai-teams/shared` 的改动需要 `pnpm build` 后才能反映到 server/agent 的 bundle 中
- 发布前确保 `.gitignore` 中包含 `dist/` 目录，不要将构建产物提交到 git
